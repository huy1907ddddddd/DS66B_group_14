# Chạy notebook bằng VS Code

Mở thư mục Midterm_Tetouan_GridWatch rồi mở notebooks/GridWatch_Next_Step_Giai_thich_tung_dong.ipynb để học, hoặc notebooks/GridWatch_Colab.ipynb cho bản ít comment.

Chọn kernel ở góc trên bên phải: GridWatch - Python 3.12. Môi trường nằm tại D:/CodexRuntimes/GridWatch_Python312/Scripts/python.exe và đã có ipykernel cùng thư viện của bài.

Chạy lần lượt từ đầu: bấm tam giác bên trái mỗi ô code hoặc Shift+Enter. Chạy lại ô import trước, sau đó đọc/chia dữ liệu, đổi tên/định dạng giờ rồi các ô EDA. Kết quả nằm ngay bên dưới từng ô.

Run All chạy cả tối ưu tham số, có thể mất khoảng 22 phút hoặc khác tùy máy. Khi chỉ học EDA, chạy các ô tới hết EDA là đủ; chưa cần chạy toàn bộ.

Notebook ưu tiên file ../data/raw/Tetuan City power consumption.csv khi thư mục làm việc là notebooks. Nếu không có file đó (ví dụ Colab), notebook dùng link dữ liệu cố định. Thay cách mở file không thay đổi cách chia dữ liệu hoặc mô hình.
