# Original dataset

Source: [UCI Power Consumption of Tetouan City](https://archive.ics.uci.edu/dataset/849/power+consumption+of+tetouan+city).

`Tetuan City power consumption.csv` is copied without changes from the downloaded UCI dataset. It contains 52,416 data rows and nine columns at ten-minute intervals. Column names and numeric values in this file remain unchanged. Prepared features are generated separately.

Demand values retain their source units. No outage, capacity or equipment-fault labels are provided.
